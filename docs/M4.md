# M4: complete development integration; acceptance pending

Original source: [Bigyehahaha/M4](https://github.com/Bigyehahaha/M4), fixed commit `2b0f92ef872fcd9997f1ae6b4ba6565fc53eb332`, MIT copyright2024yezhang. The full architecture contains five MP-AMIL experts, each with learned512D projection, full square-grid duplicate padding, depthwise convolutional positional encoding, four channel groups with3/5/7 depthwise-separable convolutions and gated attention. Each endpoint uses four distinct expert-gate vectors, one per128D channel slice. Every task has its own512→32→1 sigmoid tower with dropout0.4. Original unused expert classifiers remain allocated; they must not be falsely reported as trained. The source grid is a sequence-derived grid, not a claim of true physical-coordinate geometry.

The actual release script uses32epochs and10binary endpoints. Training sums all ten source BCELoss objectives on sigmoid probabilities; it does not average tasks or replace this with mutually exclusive classification. The optimizer is Adam1e-4 with4e-5 weight decay over all parameters, followed once per epoch by the main routine's LambdaLR cosine schedule with final factor0.1. There is no early stopping. Checkpoint selection uses strict improvement in validation mean endpoint AUROC. The separate warmup scheduler.py is unused by this source route and should not replace it.

The native reference must retain2048D RetCCL inputs, all512D internal widths, five experts, ten endpoints and complete variable-size bags. Different FM input dimensions are explicit ports through the author's feat_input argument. Native reference budgets and those ports are reported separately.

The original data split is a fixed20% outer patient test set (seed42) and five repeated train/validation splits within the remaining patients (validation20%, seeds0–4). These are not five mutually exclusive test folds. Slide-level training, complete patient grouping across splits, original input row order and the RNG effects of both shuffled TRAIN and shuffled VAL DataLoaders must be preserved or explicitly documented as benchmark split ports. Dataset.py imports the removed parser module; loading only actual dataset definitions avoids this unused import without removing a training stage.

Every endpoint needs explicitly measured binary labels with ordered names and provenance. Missing, unknown or untested genes must never be turned into negative labels. The original global sorted-value label remapping is not a biological definition of mutation-positive; actual endpoint coding must be registered explicitly. Validation and test must contain both labels per endpoint for the source AUROC definition.

Complete target/provenance binding, original optimizer/data-loader/scheduler training, VAL-only selection and CLI/catalog routing are implemented. Actual full2048D/512D/5expert/10task two-epoch original-source comparison matches every network tensor, Adam moment/counter, cosine state and global RNG. Actual full-state disk recovery matches uninterrupted training. The unified CLI trained and independently reloaded twice for both2048D native input and an explicit1024D FM input port. No original unused expert classifier was falsely credited with updates. Full32epoch native budgets, whole-library and final installed-wheel gates remain pending. No real WSI or paper-score result is claimed.
