# ZoomMIL：来源核查与接入边界

本工作目录为完整公开三尺度路线的0.69隔离开发候选，**尚未正式验收**。
正式主库为0.62的117/164条；新候选写入完整训练后达到124条，但需要当前版本专项、原生预算和全库准入。

固定官方来源为 [histocartography/zoommil](https://github.com/histocartography/zoommil)，
commit `da7bb7fa71629d34e9b04859c1db791ac8330f5d`，已核查MIT许可。
已阅读18页 [ECCV论文](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136810689.pdf)，
以及模型、扰动Top-K、trainer、数据集、配置、保存器、预处理和递归层级排列的完整相关源码。

## 已取得与已验证

`zoommil_source.py`私有加载原始完整三层网络与实际扰动Top-K的前向及自定义反向。
保留每层512维表示、256维门控注意力、两个独立辅助选样注意力、三层表示相加、
原始Kronecker选样及100次高斯扰动；未用普通Top-K替代训练时可微选样。
只将Kronecker恒等矩阵的设备分配从构造时猜测的CUDA改为实际输入设备。
`.to(device)`控制整体放置，不修改原始网络数值路径。

在原生1024维、16/64/1024个完整层级节点的BRIGHT比例条件下，已与直接加载的原模型
对照训练输出、CE、全部输入梯度、全部参数梯度、两个辅助选择头的非零梯度、随机流，
并检查评估时硬Top-K不消费随机数。1536维完整FM输入的当前专项检查另行保存，
不得用原1024维单项结果冒充其通过。

当前已写入实际层级准备、真实level0坐标转换、完整source训练控制器、加权DataLoader、Adam/plateau及恢复，
并提供两个明确的执行配置。R1的18项数据/9项训练、R2的0与8读进程原始trainer对照与CLI验证均保留，
最终当前版本35项专项与独立安装包完整100轮预算、全库/全部235配置分别验收。
规格为 `adapted`，配置仍为 `implemented_unvalidated`，没有自然WSI或论文指标复现。

## 原始训练约定

- 原始Adam：lr1e-4、betas(0.9,0.999)、eps1e-8，`reg`默认为0。
- ReduceLROnPlateau依据逐slide的验证CE均值，sample_config明确factor0.8/patience5；
  Config类在没有显式字段时的factor默认0.5，必须区分。
- 完成100轮、batch1，不提前停止。默认按类别逆频率的WeightedRandomSampler有放回抽取N张训练切片。
  DataLoader每次创建迭代器也会消费base seed；验证顺序加载仍有这一随机流影响。
- 原生精度为普通FP32；源码没有autocast/GradScaler，不应默认以AMP改变此方法。
- 三层sample_config：1.25x/2.5x/10x、K12、sigma0.002、dropout0.25、三分类、1024维输入。
  CRC论文三层为5x/10x/20x、K16、验证loss选模；BRIGHT采用weighted-F1。
- ModelSaver的loss分支读取`val_loss`，但实际传入val_summary没有该字段；需要显式修复并披露。
  F1初始化为0会在所有验证F1都为0时不保存任何模型；应定义首个有效模型的边界，不能假称原代码始终产生文件。

已保留Adam与scheduler全部状态、实际抽样顺序、CPU/CUDA随机源、验证与选模行为、
学习率轨迹与epoch边界精确恢复；默认100固定轮且不提前停止。
R1的workers0为历史软件条件，R2默认恢复原生8进程读取，并直接对照原数据集/训练器验证0和8两种条件。

## 层级数据约定

原始H5保存每层`<magnification>x_patches`及`<magnification>x_coords`。
低倍坐标为实际row/col；更高层坐标包含低倍坐标与所有递归分支的row/col前缀。
子块顺序为`(0,0),(1,0),(0,1),(1,1)`，不能按常见的另一种行列扫描顺序猜测。
预处理以低倍组织mask筛根节点，并保留每个已保留根的全部高倍后代。

BRIGHT中间到高倍跨两级，必须提供每个中倍节点16个高倍后代；
low/mid/high完整行数比例为1:4:64，不能把三个不对应的FM特征文件按行数reshape为层级。
CRC三层比例为1:4:16。准备工具需要验证实际前缀/坐标、完整覆盖、无重复、相同FM及权重/预处理、
基本特征与所登记低倍特征一致，并绑定所有文件哈希、患者与划分。

TRIDENT等工具的普通二维坐标不是原源码的递归前缀索引。当前支持以实际level0左上角xy坐标、
倍率和真实patch边长转换；验证网格相位、父子覆盖及完整后代，不从特征行号或包大小伪造坐标。
不同切片可读取各自H5中登记的真实边长。独立倍率文件需要按实际对应关系整理到声明的H5字段。

## 论文与公开版本的差异

公开模型固定解包三个输入。论文包含两层CAMELYON16与ZoomMIL-Eff，以及按选择区域再提取FM特征的在线推理。
不能通过重复同一尺度、零向量或跳过中间计算，把三层源码伪装成已复现这些条件。
两层版本应依据论文另行命名、实现与验收；原图按需FM提取也需要单独记录成本和验证。
公开trainer在推理时仍读取完整缓存特征，不构成论文整体WSI效率结论的复现。

论文将classifier描述为两层MLP，公开模型实际为求和后单个Linear；源码参考必须保留实际代码，
不能在相同方法名下悄悄增加一层。任何论文重建版本需独立登记。
