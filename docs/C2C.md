# Cluster-to-Conquer: complete end-to-end C2C

Original source: [YashSharma/C2C](https://github.com/YashSharma/C2C), MIT,
commit `d53b6350372117bf3e5251044a856e0251d810b2`. The original authors
provide the full train loop, dynamic clustering, sampling, three losses and
all-patch evaluation. This adapter retains them. It is a raw-image/encoder
training method; a frozen FM feature matrix alone cannot run original C2C.

| Execution profile | Condition |
| --- | --- |
| `c2c_cluster_source` | Binary full clustering route and original Notebook BN setting |
| `c2c_cluster_default_bn_source` | Binary full clustering route with the author's alternate constructor-default BN setting |
| `c2c_cluster_multiclass_repaired` | Explicit C-way weak patch-label/evaluation extension, retaining the full original network and all three objectives |

`C2C` and `Cluster-to-Conquer` resolve to the original Notebook BN profile for
binary tasks; a C-way task explicitly resolves to the named multiclass repair,
which is saved in the run request. Source results are not silently attributed
to a different backbone, partial loss, top-k ablation or modern BN behavior.

## Inputs and public commands

```bash
pip install '.[c2c]'
milplus setup --method C2C
```

The setup command fetches the fixed author source and checksum-verified
historical support assets. GPU tasks use local prepared assets and require no
public download during training. Original ImageNet weights are
`resnet18-5c106cde.pth`, SHA256
`5c106cde386e87d4033832f2996f5493238eda96ccf559d1d62760c4de0613f8`.
The newer torchvision ResNet18 checkpoint is not silently substituted.

Each raw-image index row points to a packed HDF5 bag:

```text
pixels       uint8 [N,H,W,3], original RGB bytes
patch_ids    UTF8 [N], unique stable original patch identities
coords       optional int [N,2], only when actual coordinates are provided
```

Real patches are never generated by reshaping FM features. Their original RGB
bytes, dimensions, order and identities are preserved. C2C does not consume
physical coordinates; use `path_identity_only` when coordinates are not
available. Do not manufacture a spatial grid to fill that optional field.
Embedded pixels and IDs are required; unregistered external/virtual HDF5
storage and FM feature matrices are rejected.

For the author's original CSV format (`wsi,path`), an optional CPU packing tool
retains the literal `cv2.imread` then `cvtColor(BGR2RGB)` decoding pipeline:

```bash
pip install '.[c2c-source-audit]'
milplus pack-c2c --table original_tiles.csv --output packed_rgb
```

The tool writes `images.csv`, packed bags and a receipt containing original
file hashes. It preserves within-slide CSV order and neither resizes nor
normalizes images. Prepare patient, label and split tables independently; the
packer does not guess patient IDs or assign labels from folder names.

The task bundle uses `dimension: 3`, `training_unit: slide`,
`evaluation_unit: slide` and the raw-image index. A schema JSON declares:

```json
{
  "schema_version": 1,
  "kind": "c2c_original_rgb_patch_bags",
  "layout": "NHWC",
  "dtype": "uint8",
  "color": "RGB",
  "normalization": "albumentations046_ToTensor_no_normalize",
  "coordinate_frame": "path_identity_only",
  "patch_pixels": 512,
  "pixel_key": "pixels",
  "patch_ids_key": "patch_ids",
  "image_provenance": "Actual original WSI or OpenCV tile decoding and version",
  "patch_provenance": "Actual crop/size/scale, original patch identities and row order",
  "asset_root": "/absolute/path/to/c2c_assets"
}
```

`patch_pixels` must equal the actual packed images. Training never silently
resizes to a preferred dimension. Historical assets default to
`~/.cache/milplus/assets/c2c`; `MILPLUS_C2C_ASSETS` can select another dedicated
root. Asset sources/checksums are in `milplus.c2c_assets.ASSETS`.

```bash
milplus prepare-c2c --data TASK --schema schema.json --output c2c/manifest.json
```

Then set the selected encoder's `c2c.manifest: c2c/manifest.json` in
`task.yaml`. The manifest binds all RGB bag hashes, exact patch-ID order,
historical pretrained/source assets, labels, patients and disjoint splits.

```bash
milplus run --data TASK --method C2C --output runs/c2c
milplus evaluate --run runs/c2c --subset test
```

## Preserved mechanisms and source-version details

The complete original network is pretrained ResNet18 followed by512→256→64,
64→32→1 attention, and separate64→C bag/patch heads. The encoder is trained,
not replaced by a frozen mean-feature or linear network.

At every epoch, all TRAIN patches are encoded in128-image batches, L2-normalized
and passed to the actual source FAISS Kmeans route. K is `min(8,N)` exactly as
released. The training loader loops through eight cluster IDs, uses Python
`random.shuffle` within each cluster and selects up to eight real members.
It does not pad a small cluster, force every bag to64 patches, or skip dynamic
reclustering. Current integration explicitly records the modern CPU FAISS
package and thread count. This dependency port is not a claim that historical
FAISS/CUDA binaries or paper scores were reproduced.

The objective is exactly bag CE +.01 weak patch CE +.01 KL. Original KL is
`KL(uniform || softmax(raw_attention))` within each sampled cluster; groups with
**at most four** members are skipped as in the released function. The public
Notebook uses `topk=True`, which forces one cluster/64 top patches and sets the
KL coefficient to0. That is an ablation and is not used as complete C2C.

Two subtle historical dependencies are explicitly retained:

1. **BatchNorm:** the Notebook toggles `track_running_stats=False` after
   pretrained BN modules already exist. PyTorch1.5's forward uses
   `training or not track_running_stats` and always passes existing running
   buffers. Those buffers therefore still change. Modern PyTorch behaves
   differently after that same property assignment. This adapter executes the
   exact checksum-verified PyTorch1.5.1 BN forward with the actual official
   torchvision0.6.1 ResNet definitions, rather than silently using modern BN.
   Source clustering shares the model's encoder, so its eval-time BN buffer
   updates must be retained. Validation deep-copies the model and normalizes
   actual128-image chunks within each WSI, including the true final chunk.
2. **ToTensor:** original Albumentations0.4.6 divides uint8 by255 and uses no
   ImageNet mean/std, resizing or augmentation. Its surrounding Compose still
   consumes one Python RNG draw per image at p1. That draw affects later
   per-cluster sampling and is preserved, independently tested against the
   original historical calls.

The original source weak patch labels use `if bag_label==1 else0`. The named
multiclass repair extends this to the actual C-way bag class; it also exports
C-way probabilities/metrics. Original binary profiles remain binary.

Default full recipe follows `train_model`'s25epoch cap, Adam1e-4, weight-decay0,
batch1 WSI, with no scheduler, early stop, clipping or FM-feature subsampling.
The Notebook's one-epoch top-k example is not a historical training-budget
certificate. Validation uses all patches and selects accuracy with the latest
exact tie. TEST is never read for fitting, clustering or model selection.

Recovery retains all CNN parameters/BN buffers, complete Adam, actual per-epoch
WSI orders and sampled patch indices, last FAISS labels/distances/centroids,
their histories and global RNG. Independent evaluation rebuilds the actual
selected image model. Source/pixel checks and short synthetic runs are separate
from full native512-image/25epoch installed-wheel budgets. Real WSI training
and historical paper-score reproduction remain unverified until explicitly
recorded.
